# Pano: Sanat (2026-11-25)

## Okumadan önce
- **Kanıt durumu:** Analiz yalnızca web aramasına dayanıyor (8 arama, çoğu satıcı blogu). YouTube Data API verisi yok (403). Sanata özgü tek bir izlenme verisi yok; Türkçe sanat Shorts verisi yok (analiz/sanat.md satır 6-10, 13, 16, 61). Bu panodaki hiçbir fikir "çok izlenir" diye sunulmuyor. ÜRET kararı, "test videosu olarak üret" anlamına gelir.
- **Puanlama:** Her ölçüt 1-5. Toplam = (Kanca + Shorts + 2×Kanıt + 2×Doğruluk + Üretilebilirlik + Politika) / 8.
- **Kanıt puanı:** 1 = kanıt yok. 2 = tek, zayıf, dolaylı sinyal.
- **Doğruluk puanı:** DOĞRU = 5. KISMEN DOĞRU (düzeltmeler uygulandı) = 4. EFSANE (efsane çerçevesiyle) = 3. DOĞRULANAMADI veya doğrulayıcıdan geçmedi = 2. YANLIŞ = panoya girmez.
- **Karar kuralı:** ÜRET = doğrulayıcıdan geçti ve toplam ≥ 3,00. YEDEK = doğrulanmadı / DOĞRULANAMADI ya da toplam < 3,00. RED = YANLIŞ ya da toplam < 2,50.
- **Ortak şartlar:** Görseller açık illüstrasyon/çizim tarzında; gerçekçi tarz çıkarsa "altered or synthetic" işareti. Hazır müze fotoğrafı ve hazır 3D model yok; 3D eserler kendi modelimiz. Müzikte çağdaş kayıt ve "kamu malı kayıt" kullanılmaz; yalnızca notadan kendi MIDI yorumumuz. Yüklemeden sonraki ilk 24 saat Content ID kontrolü. "Çocuklar için yapılmamıştır". Kapanış cümlesi kalıbı ("X değil, Y") videodan videoya tekrarlanmaz.
