# Mitoloji: doğrulama (2026-11-25, 2. tur ile tamamlandı)

Kapsam: kısa liste 1, 3, 7, 8 (fikirler/mitoloji-revize.md).

**Yöntem sınırı (önemli).** en.wikipedia.org, islamansiklopedisi.org.tr gibi sayfalar açılamadı (ağ izni yok). Bağlantıların hiçbirini tam metin okumadım; tüm kontrol web arama özetlerine dayanıyor. Bağlantılar arama sonuçlarında çıkan sayfalardır. "İki bağımsız kaynak" ölçütünü karşılayamayan satırlar DOĞRULANAMADI. Üretimden önce birincil metinle (Dede Korkut nüshası/Ergin, Beckman 1982, Hoffner) satır satır kontrol şart.

Etiketler: DOĞRU / KISMEN DOĞRU / EFSANE / YANLIŞ / DOĞRULANAMADI.
